# Security policy

## Report a vulnerability

Do not open a public GitHub issue for suspected vulnerabilities, exposed credentials, or abuse
that could put users or the hosted service at risk.

Contact [vidIQ Support](https://support.vidiq.com/) or email
[support@vidiq.com](mailto:support@vidiq.com) with the subject **Security report** so the request
can be handled confidentially. Include the affected surface, potential impact,
reproducible steps, relevant timestamps, and a safe way to contact you.

Do not include live customer data, access tokens, destructive payloads, or unnecessary personal
information. Give the team a reasonable opportunity to investigate before public disclosure.

This policy does not promise a bug bounty, reward, safe-harbor terms, or a particular response
time.

## Scope

Non-sensitive problems with client manifests, connection metadata, workflow skills, or
documentation may use GitHub issues. Security-sensitive problems must use the confidential
reporting route above.
